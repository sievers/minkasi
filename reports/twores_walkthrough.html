What examples/twores_ex.py does, step by step

Branch needlet, written 2026-10-23. Companion to needlet.html, which holds the tests and numbers behind the choices below.

0. The idea in one paragraph

MUSTANG-2 (M2) TODs constrain the small scales of a field but lose the large scales to common-mode subtraction; ACT maps constrain the large scales. We want one map that uses both. The map is represented in a needlet (wavelet) basis, a stack of bands, each covering a range of angular scales. In that basis the normal matrix ATN-1A (“ANA”) of the TODs and the inverse covariance of the ACT map can be added, and the map solved from the sum. The script builds that sum and then solves it, either with a cheap approximate inverse (--direct) or with conjugate gradient on the real operator (--cg N, recommended).

1. Notation

xiWavelet array, shape (nfilt, nx, ny). WavSkyMap.map holds it.
FiNeedlet filter of band i, a real symmetric window in Fourier space with Σi Fi2 = 1.
real mapwav2map_real(x) = Σi Fi xi. The inverse direction, map2wav_real(m), gives xi = Fi m. The two are adjoints because Fi is real and symmetric.
MThe hits mask (diagonal, 0/1) in real space.
A, NTOD pointing and the per-TOD noise model.
operatortodvec.dot(x) = F M ATN-1A M Σj Fj xj, band by band.
GiThe diagonal (same-band) block of the operator, probed on the downsampled lattice of band i: Gi = KTOK, with K the map from lattice coefficients to the band-limited real map (band2map of an impulse on the lattice).


The needlet bands in Fourier space (10 bands, from the largest to the smallest scale).

2. Which path the flags select

FlagsFinal map
(none)PCG map for the small scales, plus a block-solve correction for the overlap bands (residual mode). Original design.

3. Step by step

Step 1: read the TODs (read_tods)

  • List Sig*.fits, drop the blacklisted TODs for the source (minkasi.get_bad_tods, cut_blacklist; 32 of 138 for MOOJ1142), keep the first --ntods-total, then give every nproc-th file to each MPI rank (at most --ntods per rank).
  • Per TOD: truncate to a good length, downsample if sampled faster than needed, then subtract a common mode plus polynomial per detector (fit_cm_plus_poly). The large scales of the sky are partly removed here, which is why M2 alone cannot constrain them.

Step 2: build the map and the needlet (setup_wmap)

  • Take the TOD limits, pad by --pad-frac (0.25) on every side (the filters are periodic, so this moves wrap-around artefacts away from the data), and make a square map whose size is a highly composite number so that bands can be downsampled by many factors.
  • Build --nfilt (10) needlet filters on that grid and wrap everything in a WavSkyMap: the wavelet array plus a real-space SkyMap counterpart.
  • get_downsamps (called later) gives each band the coarsest lattice that does not undersample it: downsamps[i], with retained pixel indices nx_space[i], ny_space[i]. Large-scale bands live on very few points, the finest band on (nearly) the whole grid.

Step 3: pointing, first noise model, hits, mask

  • Pixel indices per TOD (wmap.get_pix), and a first noise model per TOD (NoiseSmoothedSVD: a detector SVD with smoothed power spectra).
  • make_hits counts hits per pixel; rank 0 writes _hits.fits.
  • set_mask(hits, min_hits-1) makes a boolean mask hits ≥ min_hits. It is applied inside WavSkyMap.map2tod and tod2map, so every operator seen later, including the probed ones, is M ATN-1A M.

Step 4: PCG in the wavelet basis

  • The rhs is b = make_rhs = Fi M ATN-1d (tod2map ends in map2wav_real). Ordinary minkasi PCG (run_pcg_wprior) with a hits preconditioner (1/hits in every band) runs --maxiter (50) iterations.
  • This map is cheap but unconverged. Its use depends on the mode: in residual mode it is the small-scale map and is later subtracted from the data; in --direct mode it only cleans the noise model (step 5). It is written to _need.fits.

Step 5: re-estimate the noise with the model

The PCG map is projected back to TOD space (map2tod). With --direct the noise model is re-fit on dat_calib − model, so the noise estimate is no longer contaminated by signal, but the data keep the signal. Without it, the model is subtracted from the data and the noise is fit on the residual. The rhs is rebuilt with the new noise model.

Step 6: M2 response matrices Gi (get_response_matrix → probe_band)

This is the expensive step. We cannot form ANA directly, but we can apply it (todvec.dot), so we probe it. For band i:

  1. Put an impulse on a lattice point, map it to a band-limited real map (band2map, i.e. K), apply the masked operator, filter back (map2band) and read off the lattice values: one column of Gi.
  2. One TOD pass per lattice point would be exact but slow. Instead, impulses further apart than the window are summed into one map (color_groups assigns lattice points to colours that are at least a window apart) and probed together. Only entries within radius of the impulse are kept (--radius, 30 pixels, scaled per band to a few filter extents). The result is sparse and symmetrised.
  3. Bands with at most --exact-below (5000) lattice points are done exactly, one pass per point, because truncating their long-tailed kernels is what makes G indefinite.
  4. Results are cached per band in --cache. The cache does not record how the matrices were made (TODs, mask, radius, units): use a new directory or --redo when these change.

Every pass is an MPI-reduced todvec.dot, so the matrices describe all TODs on all ranks; every rank holds a copy. Typical cost: 15 min for 40 TODs on 16 ranks.

Step 7: ACT (read_act, get_response_matrix_map)

  • Read the ACT splits (--act-glob), cut a box around the field, convert μKCMB to M2 units (act_conversion, from frequency and beam), and regrid map and inverse variance to the M2 pixelization with SkyMapTwoRes.coarse2fine. The ACT-only coadd is written to _act.fits.
  • The ACT inverse covariance is the diagonal map-space ivar, a placeholder (see the TODO in the code). Optionally an edge taper (--taper, default 0 = off).
  • ACT sees the sky through its beam and pixel average: forward = beam (Fourier multiply), then block-average over ACT pixels; adjoint is the transpose. The ACT term of the operator is F adjoint(ivar · forward(Σj Fj xj)).
  • ACT is only used in bands the beam transmits: band_transfer gives the beam’s transfer per band and ACT is used where it is ≥ --act-min-transfer (0.05). With the 2.1′ beam that is bands 0–3 (transfer 0.96, 0.83, 0.53, 0.13). Deconvolving the other bands would only amplify noise.
  • ACT's rhs is map2wav_real(adjoint(ivar · act_map)), zeroed outside those bands; its Gi is probed the same way as M2's (cheap: 1 s here, no TODs).

Step 8: solve

Total precision per band: Gi = GM2,i + GACT,i; total rhs b = M2 rhs + ACT rhs.

8a. The block solve (solve_bands, via block_solver)

This is a band-diagonal approximation to G-1b: it keeps each band’s own response and drops the cross-band blocks Gij, i ≠ j. block_solver factorizes once and returns solve(rhs). For each band with a response:

  1. Sum the response matrices (M2 + ACT).
  2. Estimate the smallest eigenvalue lmin (min_eigenvalue: dense below 2500 points, otherwise ARPACK with a fixed start vector, so every rank gets the same number).
  3. Add a diagonal shift: ridge × mean(diag G) + max(0, −1.1 × lmin), with ridge = 1e-3. The first term is a zero-mean prior that keeps unconstrained modes from amplifying noise. The second makes G positive definite when truncation has made it indefinite (it is, for bands 5–9 in production).
  4. Factorize: sparse LU (splu) up to 20000 lattice points. Above that a Jacobi-preconditioned CG, run to convergence (inner=None) or for exactly --inner iterations (a fixed linear operator, needed when used as a preconditioner).

Applying solve(rhs) then does, per band: bi = Fi rhsi sampled on the lattice; ci = (Gi + shift)-1 bi; write ci onto the lattice (zeros elsewhere) and return Fi Z ci as the band’s wavelet array. Because rhsi already contains one Fi, the real map from wav2map_real is Σi Fi2 Z Gi-1 Fi2 r in terms of the real-space rhs r; for white noise that reduces to r because Σ Fi2 = 1.

Limits of the block solve alone (--direct without --cg): it is not a solution of the full system. A band’s rhs has components in modes its own block cannot constrain; the ridge then amplifies or damps them. On 40 TODs it gets 93% of the CG source peak but the extended structure correlates only 0.3–0.6 with CG. Use it as a quick look at compact sources or as a preconditioner.

8b. CG on the full operator (--cg N)

  1. apply(x) = todvec.dot(x) (M2 operator, all bands, MPI-reduced) + ACT term (bands 0–3 only). This is the true, band-coupled operator, so cross-band coupling is included.
  2. Preconditioner = the block solve with --inner (20) inner iterations: a fixed, symmetric positive definite operator (checked: asymmetry 4e-11).
  3. pcg iterates x ← x + α p with the usual preconditioned-CG recurrences until --cg-tol or N iterations. The preconditioner only changes how fast CG converges, not where it converges to.
  4. Output map: wav2map_real(x) × mask.

Step 9: outputs (--outroot)

_hits.fitsHits map.
_need.fitsThe 50-step PCG map from step 4.
_act.fitsACT coadd on the M2 grid (M2 units).
_combined.fitsOutput of the solve in step 8.
_final.fitsWith --direct/--cg identical to _combined; in residual mode, _combined + the PCG map.

4. Known caveats

  • Probed matrices are approximate. Truncating Gi to radius makes it indefinite in the fine bands; the shift fixes the solve but damps modes. In CG this only costs preconditioner quality.
  • Block solve drops the cross-band blocks (section 8a). The CG fixes this.
  • ACT noise is a diagonal ivar and ACT only constrains bands 0–3.
  • Large scales converge slowly. After 40 CG iterations scales below ~12″ are converged to under 8%, but scales of 1′ and above still change by 33–49% between iterations 40 and 80. The residual norm (flat at 3–4e-4) does not show this: part of the rhs lies outside the operator’s range, so the residual cannot go below it. Why ACT does not speed the large scales more is not understood.
  • MPI reduction bug, fixed. SkyMap.mpi_reduce used to chunk wavelet maps by nx*ny and so only reduced band 0 on large maps. Any multi-rank wavelet result from before the fix with nx*ny > 1e5 (e.g. the 138-TOD map) is wrong.
  • Response cache does not record settings (step 6).

6. Typical commands

cd examples
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 NUMBA_NUM_THREADS=1 \
mpirun -n 16 --bind-to core python twores_ex.py --name MOOJ1142 \
    --ntods 3 --ntods-total 40 --direct --cg 40 --cg-tol 1e-4 --min-hits 20 \
    --outroot OUT/MOOJ1142 --cache OUT/cache

--ntods is per rank, --ntods-total caps the total; --debug uses one TOD, 6″ pixels and fewer bands and iterations. Plots: plot_final_aplpy.py (final figure), compare_gif.py (comparison with the PCG examples), cg_convergence.py (convergence per scale).
